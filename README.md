# Early Prediction of PTSD Using Explainable Multimodal Machine Learning

## Overview
This project predicts the early risk of Post-Traumatic Stress Disorder (PTSD) using a multimodal machine learning approach. It combines clinical, lifestyle, and emotional features to improve prediction accuracy and uses Explainable AI (SHAP) to interpret predictions.

## Features
- Data preprocessing and feature engineering
- Multimodal dataset integration
- Machine learning models:
  - Logistic Regression
  - Random Forest
  - XGBoost
- SHAP-based Explainable AI
- GUI developed using Python
